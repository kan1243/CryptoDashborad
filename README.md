# Cryptocurrency DashBoard (Tkinter)
This project is a simple cryptocurrency dashboard.

## Feature
- Real-time crypto price via Websocket
- Support 5 specific cryptocurrencies
- color price based on change
- 24-hr volume display
- Last update timestamp
- Toggle button that show adition coin
- OOP design using classes

## How to Run
1. Install required library:
   pip install websocket-client

2. Run the program:
   python my_project.py
